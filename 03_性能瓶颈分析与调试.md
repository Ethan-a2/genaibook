### 2. 图像生成推理阶段

**具体表现**:
- 单张图像生成时间：10-60秒（T4 GPU）
- 批量生成时线性增长的时间消耗

**根本原因**:

**复杂度分析**:
- 时间复杂度：O(T × H × W × C)，T=时间步数(通常50)，H,W=图像尺寸
- 空间复杂度：O(H × W × C × 4)，包含中间激活值和梯度

```python
    print(f"推理步数: {num_inference_steps}")
    
    # 文本编码阶段
    with timer("文本编码"):
        text_embeddings = pipe.text_encoder(

        )[0]
    
    # 噪声初始化

        latents = torch.randn(
            (1, pipe.unet.in_channels, 64, 64),
            device=pipe.device,
            dtype=torch.float16
```

#### 步骤3.2: 内存使用监控
```python
import torch
import threading
import time
from collections import deque

class GPUMemoryMonitor:
    """GPU内存使用监控器"""
    
    def __init__(self, interval=0.1):
        self.interval = interval
        self.memory_history = deque(maxlen=1000)
        self.monitoring = False
        self.thread = None
    
    def start(self):
        """开始监控"""
        self.monitoring = True
        self.thread = threading.Thread(target=self._monitor)
        self.thread.start()
    
    def stop(self):
        """停止监控"""
        self.monitoring = False
        if self.thread:
            self.thread.join()
    
    def _monitor(self):
        """监控线程"""
        while self.monitoring:
            if torch.cuda.is_available():
                allocated = torch.cuda.memory_allocated() / 1e6  # MB
                reserved = torch.cuda.memory_reserved() / 1e6    # MB
                self.memory_history.append({
                    'time': time.time(),
                    'allocated': allocated,
                    'reserved': reserved
                })
            time.sleep(self.interval)
    
    def get_peak_memory(self):
        """获取峰值内存使用"""
        if not self.memory_history:
            return 0, 0
        peak_allocated = max(m['allocated'] for m in self.memory_history)
        peak_reserved = max(m['reserved'] for m in self.memory_history)
        return peak_allocated, peak_reserved
    
    def plot_memory_usage(self):
        """绘制内存使用曲线"""
        if not self.memory_history:
            print("没有内存使用数据")
            return
        
        import matplotlib.pyplot as plt
        
        times = [m['time'] - self.memory_history[0]['time'] for m in self.memory_history]
        allocated = [m['allocated'] for m in self.memory_history]
        reserved = [m['reserved'] for m in self.memory_history]
        
        plt.figure(figsize=(10, 6))
        plt.plot(times, allocated, label='已分配内存', linewidth=2)
        plt.plot(times, reserved, label='已预留内存', linewidth=2)
        plt.xlabel('时间 (秒)')
        plt.ylabel('内存使用 (MB)')
        plt.title('GPU内存使用监控')
        plt.legend()
        plt.grid(True)
        plt.show()

# 使用示例
```
